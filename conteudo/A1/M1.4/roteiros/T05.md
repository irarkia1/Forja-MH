# M1.4.T05 — Timers avançados (captura, PWM complementar)

> Tópico de **elite** (laboratório). Tempo previsto: ~25 h — ≈ 6,5 h de estudo (capítulos de timers dos RMs e a nota AN4776), ≈ 4 h de exemplos resolvidos e cálculos, ≈ 10,5 h de laboratório, ≈ 4 h de relatório e revisão. No M1.2 você usou os timers de 8 e 16 bits do AVR para CTC e PWM. Os timers do STM32 são a mesma ideia com muito mais recursos: prescaler de 16 bits, quatro canais de captura/comparação, contagem para cima, para baixo e centralizada, registradores com pré-carga, gatilhos entre timers, DMA e, no TIM1, saídas complementares com tempo morto e entrada de emergência — o que se usa para acionar uma meia-ponte de motor ou de fonte chaveada.

## Ao final você consegue
- Configurar a base de tempo dos timers (PSC, ARR, CNT, sentido de contagem, UG e ARPE) e calcular PSC e ARR para uma frequência ou período alvo.
- Gerar PWM alinhado à borda e ao centro nos modos 1 e 2 (CCMRx, CCER, CCRx e pré-carga) e calcular frequência, ciclo de trabalho e resolução.
- Medir período, frequência e largura de pulso por captura de entrada (CCxS, ICxF, ICxPSC e o modo PWM input com reset pelo escravo) tratando o estouro do contador.
- Gerar PWM complementar com tempo morto no TIM1 (canais CHxN, BDTR, DTG, MOE e entrada BKIN) para uma meia-ponte e calcular o tempo morto.

## Resumo
**1. Os timers do F103 e do F401/F411.**

| Timer | Tipo | Bits | Barramento | Recursos extras |
|---|---|---|---|---|
| TIM1 (F1 e F4) | avançado | 16 | APB2 | saídas complementares, tempo morto, break, contador de repetição |
| TIM2, TIM3, TIM4 (F1) | uso geral | 16 | APB1 | 4 canais, encoder, gatilhos |
| TIM2, TIM5 (F4) | uso geral | **32** | APB1 | idem, medição longa sem estouro |
| TIM3, TIM4 (F4) | uso geral | 16 | APB1 | idem |
| TIM9–TIM11 (F4) | uso geral | 16 | APB2 | 1 ou 2 canais |
| SysTick (núcleo) | — | 24 | — | só base de tempo (T04) |

Na Blue Pill a 72 MHz (APB1 ÷2, APB2 ÷1), **todos** os timers recebem f_TIM = 72 MHz (T02).

**2. A base de tempo.**
```text
 f_TIM ──► PSC (÷ PSC+1) ──► CNT conta 0..ARR ──► ao passar de ARR para 0: evento de atualização (UEV)
                                                   → flag UIF, interrupção (UIE), pedido de DMA (UDE), TRGO
```
> f_CNT = f_TIM / (PSC + 1) · f_UEV = f_TIM / ((PSC + 1)(ARR + 1))

- **Shadow registers.** O PSC é **sempre** bufferizado: o valor novo só vale no próximo UEV. O ARR é bufferizado se `CR1.ARPE = 1`. Para carregar tudo de imediato na inicialização, escreva `EGR.UG = 1` (gera um UEV por software; também liga a UIF — limpe-a antes de habilitar a interrupção, ou ganha uma interrupção espúria).
- **Sentido**: `CR1.DIR` (para cima / para baixo) e `CR1.CMS` (centralizado: sobe até ARR e desce até 0; o período passa a ser 2 × ARR contagens).
- `CR1.CEN` liga o contador. `CR1.OPM` para depois de um ciclo (pulso único).

**Exemplo 1 (escolher PSC e ARR).** 1 Hz a partir de 72 MHz: (PSC + 1)(ARR + 1) = 72·10⁶. Com PSC = 7199 → 10 kHz no CNT; ARR = 9999 → 1 Hz. Regras práticas: escolha o PSC para que o CNT tenha uma unidade "redonda" (1 µs, 0,1 ms) e use o ARR para o período; para PWM de alta resolução, faça o contrário (PSC pequeno, ARR grande).

```c
#include "stm32f1xx.h"

void TIM2_IRQHandler(void)
{
    if (TIM2->SR & TIM_SR_UIF) {
        TIM2->SR = ~TIM_SR_UIF;              /* rc_w0: escreve 0 só na UIF, 1 nas outras (não mexe) */
        GPIOC->ODR ^= GPIO_ODR_ODR13;
    }
}

void tim2_1hz(void)
{
    RCC->APB1ENR |= RCC_APB1ENR_TIM2EN;
    TIM2->PSC = 7199;                        /* 72 MHz / 7200 = 10 kHz */
    TIM2->ARR = 9999;                        /* 10 kHz / 10000 = 1 Hz */
    TIM2->CR1 |= TIM_CR1_ARPE;
    TIM2->EGR = TIM_EGR_UG;                  /* carrega PSC e ARR agora */
    TIM2->SR = 0;                            /* descarta a UIF gerada pelo UG */
    TIM2->DIER |= TIM_DIER_UIE;
    NVIC_SetPriority(TIM2_IRQn, 5);
    NVIC_EnableIRQ(TIM2_IRQn);
    TIM2->CR1 |= TIM_CR1_CEN;
}
```
As flags do `TIMx_SR` são *rc_w0* (limpa escrevendo 0). `TIM2->SR &= ~TIM_SR_UIF` é uma leitura-modificação-escrita que pode apagar uma flag de captura que chegou no meio; `TIM2->SR = ~TIM_SR_UIF` escreve 1 nas outras, que não têm efeito.

**3. PWM.** Cada canal compara CNT com CCRx e comanda a saída OCx conforme `CCMRx.OCxM`:
- **Modo 1** (110): saída **ativa** enquanto CNT < CCRx (contando para cima). Ciclo de trabalho = CCRx / (ARR + 1).
- **Modo 2** (111): o inverso (inativa enquanto CNT < CCRx).
- `CCMRx.OCxPE = 1` (pré-carga do CCR): o novo ciclo de trabalho só vale no próximo UEV — sem isso, mudar CCR no meio do período gera um pulso "torto".
- `CCER.CCxE` liga a saída; `CCER.CCxP` inverte a polaridade (ativa em baixo).
- **Resolução** = log₂(ARR + 1) bits. **Frequência** = f_TIM / ((PSC + 1)(ARR + 1)).
- **Alinhado ao centro** (CMS ≠ 00): f_PWM = f_TIM / ((PSC + 1) · 2 · ARR). Os pulsos de todos os canais ficam centrados no mesmo instante — menos harmônicos e ruído na corrente de motores e inversores, e o meio do pulso é o melhor instante para amostrar a corrente (T07).

**Exemplo 2 (PWM de 20 kHz para motor, máxima resolução).** 72 MHz / 20 kHz = 3600 → PSC = 0, ARR = 3599: 3600 passos ≈ 11,8 bits. Para 50 % de ciclo: CCR = 1800. Centralizado a 20 kHz: ARR = 72·10⁶ / (2 × 20 000) = 1800 (resolução cai pela metade).

**Exemplo 3 (servo: 50 Hz, pulso de 1 a 2 ms).** PSC = 71 → 1 MHz (1 µs por contagem); ARR = 19 999 → 20 ms. CCR = 1500 → 1,5 ms (centro).

```c
#include "stm32f1xx.h"

/* PWM de 1 kHz em PA6 = TIM3_CH1 (Blue Pill), ciclo em milésimos */
void tim3_pwm_init(void)
{
    RCC->APB2ENR |= RCC_APB2ENR_IOPAEN;
    RCC->APB1ENR |= RCC_APB1ENR_TIM3EN;
    GPIOA->CRL = (GPIOA->CRL & ~(0xFu << 24)) | (0xAu << 24);   /* PA6: AF push-pull 2 MHz (CNF=10, MODE=10) */

    TIM3->PSC  = 71;                                   /* 1 MHz */
    TIM3->ARR  = 999;                                  /* 1 kHz, 1000 passos */
    TIM3->CCR1 = 250;                                  /* 25 % */
    TIM3->CCMR1 = (TIM3->CCMR1 & ~(TIM_CCMR1_OC1M | TIM_CCMR1_CC1S))
                | TIM_CCMR1_OC1M_2 | TIM_CCMR1_OC1M_1  /* 110: PWM modo 1 */
                | TIM_CCMR1_OC1PE;                     /* pré-carga do CCR1 */
    TIM3->CCER |= TIM_CCER_CC1E;                       /* liga a saída */
    TIM3->CR1  |= TIM_CR1_ARPE;
    TIM3->EGR   = TIM_EGR_UG;
    TIM3->CR1  |= TIM_CR1_CEN;
}

void tim3_ciclo(uint32_t milesimos) { TIM3->CCR1 = milesimos; }   /* vale no próximo período */
```

**4. Captura de entrada.** Na borda escolhida, o valor do CNT é copiado para CCRx e a flag CCxIF sobe.
- `CCMRx.CCxS` = 01 (o canal x lê a sua própria entrada TIx), 10 (lê a entrada vizinha), 11 (TRC).
- `CCMRx.ICxF` (4 bits): filtro digital — a borda só é aceita depois de N amostras iguais (bom contra ruído e bounce leve).
- `CCMRx.ICxPSC`: captura a cada 1, 2, 4 ou 8 bordas (para sinais rápidos).
- `CCER.CCxP`: borda de subida (0) ou descida (1); no F4, CCxNP + CCxP = 11 captura as duas.
- `SR.CCxOF` (*overcapture*): uma nova captura chegou antes de você ler a anterior.

Período = diferença entre duas capturas × período do CNT. Com contador de 16 bits, o resultado da subtração em `uint16_t` já está certo se houver **no máximo um** estouro entre as capturas; para períodos longos, conte as UIF entre as capturas ou use o TIM2/TIM5 de 32 bits do F4.

**Exemplo 4 (com estouro).** CNT a 1 MHz, ARR = 0xFFFF. Captura 1 = 60 000, captura 2 = 4 464, uma UIF entre elas: Δ = 65 536 − 60 000 + 4 464 = 10 000 contagens = 10 ms → **100 Hz**. Em `uint16_t`: (uint16_t)(4464 − 60000) = 10 000.

**Modo PWM input.** Dois canais olham o **mesmo** pino: CH1 captura a subida (período), CH2 a descida (largura), e o modo escravo *reset* zera o CNT a cada subida. Resultado: CCR1 = período, CCR2 = largura, sem subtração e sem interrupção por borda.
```c
#include "stm32f1xx.h"

/* Mede período e largura em PA0 = TIM2_CH1 (Blue Pill). CNT a 1 MHz. */
void tim2_pwm_input_init(void)
{
    RCC->APB2ENR |= RCC_APB2ENR_IOPAEN;
    RCC->APB1ENR |= RCC_APB1ENR_TIM2EN;
    GPIOA->CRL = (GPIOA->CRL & ~0xFu) | 0x4u;          /* PA0: entrada flutuante */

    TIM2->PSC = 71;
    TIM2->ARR = 0xFFFF;
    TIM2->CCMR1 = TIM_CCMR1_CC1S_0                     /* CC1S = 01: IC1 ← TI1 */
                | TIM_CCMR1_CC2S_1                     /* CC2S = 10: IC2 ← TI1 */
                | (3u << TIM_CCMR1_IC1F_Pos);          /* filtro: 8 amostras a f_CK_INT */
    TIM2->CCER = TIM_CCER_CC1E                         /* CH1: subida (CC1P = 0) */
               | TIM_CCER_CC2E | TIM_CCER_CC2P;        /* CH2: descida */
    TIM2->SMCR = TIM_SMCR_TS_2 | TIM_SMCR_TS_0         /* TS = 101: gatilho TI1FP1 */
               | TIM_SMCR_SMS_2;                       /* SMS = 100: modo reset */
    TIM2->EGR = TIM_EGR_UG;
    TIM2->CR1 |= TIM_CR1_CEN;
}

uint32_t periodo_us(void) { return TIM2->CCR1 + 1u; }   /* contagens de 1 µs; +1 pelo reset */
uint32_t largura_us(void) { return TIM2->CCR2 + 1u; }
```
(O "+1" vem da contagem do próprio ciclo de reset; para medidas finas, calibre com um sinal conhecido — o laboratório faz isso.)

**5. TIM1: PWM complementar e tempo morto.** Uma **meia-ponte** tem dois transistores em série entre a alimentação e o GND; o ponto médio aciona a carga. Se os dois conduzirem juntos, mesmo por nanossegundos, há curto (*shoot-through*). O TIM1 gera, para cada canal 1–3, a saída OCx e a **complementar** OCxN, e insere um **tempo morto** em que **as duas** ficam desligadas a cada comutação.

Pinos do TIM1 no F103: CH1 = PA8, CH2 = PA9, CH3 = PA10, CH1N = PB13, CH2N = PB14, CH3N = PB15, **BKIN = PB12**.

Registrador `BDTR`:
- **MOE** (*main output enable*): sem ele, **nenhuma** saída do TIM1 funciona — o erro nº 1 de quem usa o TIM1 pela primeira vez.
- **DTG[7:0]**: tempo morto em unidades de t_DTS (t_DTS = 1/f_TIM se `CR1.CKD` = 00):
  - DTG[7:5] = 0xx → DT = DTG[7:0] × t_DTS (0 a 127 unidades);
  - DTG[7:5] = 10x → DT = (64 + DTG[5:0]) × 2 t_DTS;
  - DTG[7:5] = 110 → DT = (32 + DTG[4:0]) × 8 t_DTS;
  - DTG[7:5] = 111 → DT = (32 + DTG[4:0]) × 16 t_DTS.
- **BKE / BKP**: liga a entrada de break e escolhe a polaridade. Um nível ativo em BKIN **zera o MOE em hardware** (em nanossegundos, sem software) e leva as saídas aos níveis de repouso `OISx`/`OISxN`. Com `AOE = 1`, o MOE volta sozinho no próximo UEV; com `AOE = 0`, só o software religa.
- **OSSR/OSSI** e **LOCK**: estado das saídas desligadas e travamento da configuração.

**Exemplo 5 (tempo morto).** f_TIM = 72 MHz → t_DTS = 13,89 ns. 500 ns → 36 unidades → **DTG = 36** (0x24). 1 µs → 72 → DTG = 72. 2 µs → 144 unidades, acima de 127: faixa 10x → (64 + n) × 2 = 144 → n = 8 → DTG = 0b1000_1000 = **0x88**.

```c
#include "stm32f1xx.h"

/* TIM1 CH1 (PA8) + CH1N (PB13), 20 kHz alinhado ao centro, 1 µs de tempo morto, break em PB12 (ativo em baixo) */
void tim1_meia_ponte(void)
{
    RCC->APB2ENR |= RCC_APB2ENR_IOPAEN | RCC_APB2ENR_IOPBEN | RCC_APB2ENR_TIM1EN;
    GPIOA->CRH = (GPIOA->CRH & ~(0xFu << 0))  | (0xBu << 0);    /* PA8: AF PP 50 MHz */
    GPIOB->CRH = (GPIOB->CRH & ~(0xFu << 20)) | (0xBu << 20);   /* PB13: AF PP 50 MHz */
    GPIOB->CRH = (GPIOB->CRH & ~(0xFu << 16)) | (0x8u << 16);   /* PB12: entrada com pull */
    GPIOB->BSRR = GPIO_BSRR_BS12;                               /* pull-up: break inativo */

    TIM1->PSC = 0;
    TIM1->ARR = 1800;                                  /* 72 MHz / (2 × 1800) = 20 kHz */
    TIM1->CR1 = TIM_CR1_CMS_0 | TIM_CR1_ARPE;          /* centralizado, modo 1 */
    TIM1->CCMR1 = TIM_CCMR1_OC1M_2 | TIM_CCMR1_OC1M_1 | TIM_CCMR1_OC1PE;   /* PWM modo 1 */
    TIM1->CCR1 = 900;                                  /* 50 % */
    TIM1->CCER = TIM_CCER_CC1E | TIM_CCER_CC1NE;       /* OC1 e OC1N ativos em alto */
    TIM1->BDTR = (72u << TIM_BDTR_DTG_Pos)             /* 72 × 13,9 ns = 1 µs */
               | TIM_BDTR_BKE                          /* break ligado, BKP = 0: ativo em baixo */
               | TIM_BDTR_OSSR;
    TIM1->EGR = TIM_EGR_UG;
    TIM1->BDTR |= TIM_BDTR_MOE;                        /* sem isto, nada sai */
    TIM1->CR1 |= TIM_CR1_CEN;
}
```
O tempo morto **encurta** os dois pulsos: com 50 % a 20 kHz (período de 50 µs), cada saída fica ativa 25 µs − 1 µs = 24 µs. Escolha o tempo morto pelo datasheet do driver e dos MOSFETs (tempos de desligamento, atraso do *gate driver*) com margem — e confira no osciloscópio, não na fé.

**6. Ligações entre timers (para saber que existem).** Cada timer pode exportar um sinal (`CR2.MMS` → **TRGO**: o UEV, um canal) e outro pode usá-lo como gatilho, clock ou habilitação (`SMCR.TS` e `SMS`). É assim que o TIM3 dispara o ADC (T07), que dois timers se encadeiam num contador de 32 bits no F1, e que o TIM1 sincroniza a amostragem de corrente com o PWM. O **modo encoder** (`SMS` = 001–011) lê encoders em quadratura direto no CNT (M1.8).

### Passo a passo
**Experimento 1 — Base de tempo (≈ 2 h).**
1. Implemente o Exemplo 1 (TIM2 a 1 Hz) e confira com o cronômetro em 60 períodos. Depois mude para 1 kHz e confira no osciloscópio (alterne um pino na rotina).
2. Retire o `TIM2->SR = 0` depois do UG e veja no GDB (ou contando piscadas) a interrupção espúria logo após a inicialização.
3. Mude o ARR com o timer rodando, com ARPE = 0 e com ARPE = 1, numa troca de 10 000 para 100 quando CNT ≈ 5000. Explique o que acontece em cada caso (pista: com ARPE = 0 e CNT já acima do ARR novo, o contador vai até 0xFFFF).

**Experimento 2 — PWM (≈ 2,5 h).**
1. Exemplo de PWM do TIM3 em PA6: meça frequência e ciclo para CCR = 0, 1, 250, 999 e 1000. Explique os extremos.
2. Faça o LED "respirar": a cada 10 ms (SysTick), mude o CCR1 seguindo uma rampa. Compare com OC1PE = 0 e = 1 olhando no osciloscópio o período em que a mudança acontece.
3. (Opcional) Servo SG90 em TIM3_CH1 (Exemplo 3): mova de 1 ms a 2 ms e anote o ângulo.
4. Ponha dois canais com o mesmo ciclo, alinhado à borda e ao centro. Desenhe onde ficam as bordas de cada canal em relação ao CNT.

**Experimento 3 — Captura (≈ 2,5 h).**
1. Ligue um fio de PA6 (PWM do Experimento 2) a PA0 e use o modo PWM input do Resumo para medir período e largura. Faça uma tabela: valor configurado × medido, para 5 ciclos diferentes.
2. Gere frequências de 10 Hz, 100 Hz e 10 kHz. Com o CNT a 1 MHz e 16 bits, qual delas estoura? Implemente a contagem de UIF para medir 10 Hz corretamente.
3. Ligue o filtro (`IC1F`) e meça um botão: compare o número de capturas com e sem filtro.

**Experimento 4 — Meia-ponte com tempo morto (≈ 3 h).**
1. Grave o `tim1_meia_ponte()`. **Não ligue transistores**: meça só os sinais lógicos PA8 e PB13 com os dois canais do osciloscópio.
2. Meça o tempo morto nas duas bordas e compare com DTG = 72. Repita com DTG = 36 e DTG = 0x88 (2 µs).
3. Comente a linha do MOE e veja as saídas pararem. Depois aterre PB12 (break) com o PWM rodando: o que acontece com as saídas, quanto tempo leva e como religar? Teste com AOE = 0 e AOE = 1.
4. Mude o CCR1 para 0 % e 100 %: as saídas complementares continuam respeitando o tempo morto?

## Armadilhas comuns
- Esquecer o +1: frequência = f_TIM / ((PSC + 1)(ARR + 1)).
- Calcular com PCLK1 = 36 MHz em vez de f_TIM = 72 MHz (T02).
- Esquecer o UG e esperar que o PSC valha de imediato; esquecer de limpar a UIF depois do UG.
- Limpar flags do SR com `&=` e perder uma captura.
- Usar o TIM1 sem pôr MOE = 1.
- Mudar o CCR sem pré-carga e gerar um pulso deformado.
- Medir períodos longos com 16 bits sem contar estouros.
- Ligar a meia-ponte de potência antes de medir o tempo morto nos sinais lógicos.
- Deixar o pino BKIN flutuando com o break habilitado: o PWM desliga "sozinho".

## Gabarito
1. 72·10⁶ / 38 000 = 1894,7: PSC = 0, ARR = 1894 → 72·10⁶/1895 = 37 994,7 Hz (erro −0,014 %).
2. 72·10⁶/256 = 281,25 kHz, 8 bits. Centralizado: 72·10⁶/(2 × 255) ≈ 141,2 kHz.
3. CCR = 375. Em modo 2 a saída fica inativa enquanto CNT < CCR: para 37,5 % ativo, CCR = 625.
