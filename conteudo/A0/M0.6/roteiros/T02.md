# M0.6.T02 — Ponteiros e arrays

## Ao final você consegue
- Declarar, inicializar e desreferenciar ponteiros, e usá-los para que uma função altere variáveis de quem a chamou.
- Prever o resultado da aritmética de ponteiros e da relação entre arrays e ponteiros (indexação, decaimento, sizeof).
- Manipular strings C (terminador nulo, strlen × sizeof, cópia segura com tamanho limitado).
- Ler declarações com const e ponteiros, e identificar erros clássicos: ponteiro nulo, não inicializado, pendurado e acesso fora do array.

## Resumo
**1. Endereço e conteúdo.** Toda variável ocupa bytes num endereço. `&x` é o endereço de `x`; um ponteiro guarda um endereço; `*p` é "o objeto para onde `p` aponta".
```c
int x = 10;
int *p = &x;      /* p aponta para x                      */
*p = 20;          /* escreve em x: agora x == 20          */
printf("%p %d\n", (void *)p, *p);   /* endereço e valor   */
```
No GDB (T09): `p &x`, `p p`, `p *p`, `x/4xb p`. O tipo do ponteiro diz **quantos bytes** ler e como interpretá-los. `NULL` é o ponteiro que não aponta para nada; desreferenciá-lo é comportamento indefinido (no PC, segfault; num microcontrolador sem proteção de memória, pode ler o endereço 0 sem erro algum — o que é pior).

**2. Alterar variáveis de quem chamou.** C passa tudo por valor; para uma função alterar a variável do chamador, passe o endereço:
```c
void troca(int *a, int *b)
{
    int t = *a;
    *a = *b;
    *b = t;
}
/* uso: troca(&x, &y); */
```
É o padrão para "devolver" mais de um valor: `bool le_sensor(uint16_t *saida)` devolve sucesso/erro e escreve a leitura em `*saida`.

**3. Aritmética de ponteiros.** `p + 1` aponta para o **próximo elemento**, não para o próximo byte: avança `sizeof(*p)` bytes. Com `uint32_t *p`, `p + 3` está 12 bytes à frente. A diferença `q - p` entre ponteiros do mesmo array é contada em elementos (tipo `ptrdiff_t`). Só é válido apontar para dentro do array ou **uma posição depois** do fim (sem desreferenciar).
- `*p++` lê `*p` e depois avança `p` (o `++` pós-fixo se aplica ao ponteiro).
- `(*p)++` incrementa o valor apontado.

**4. Arrays e ponteiros.** `v[i]` é, por definição, `*(v + i)`. Na maioria das expressões, o nome de um array **decai** para um ponteiro para o primeiro elemento (`v` vira `&v[0]`). Exceções: `sizeof v` (tamanho do array inteiro) e `&v` (endereço do array). Consequências:
```c
int v[10];
size_t n = sizeof v / sizeof v[0];     /* 10: só funciona onde v É um array     */

void f(int v[10]) { sizeof v; }        /* aqui v é int*: sizeof dá 8 no x86-64! */
```
Um parâmetro declarado como array **é um ponteiro**: o tamanho se perde. Por isso as funções C recebem o ponteiro **e** o tamanho: `uint16_t media(const uint16_t *v, size_t n)`. O gcc avisa (`-Wsizeof-array-argument`). Arrays não podem ser atribuídos (`a = b` não compila) — copie com `memcpy(a, b, sizeof a)`.

**5. Strings C.** Uma string é um array de `char` terminado pelo byte nulo `'\0'`.
```c
char nome[] = "LED";        /* 4 bytes: 'L' 'E' 'D' '\0'              */
char buf[16] = "sensor";    /* 16 bytes; strlen(buf) == 6               */
const char *msg = "OK";     /* aponta para um literal (memória só de leitura) */
```
- `strlen` conta caracteres até o `'\0'` (sem contá-lo); `sizeof` dá o tamanho do array em bytes. Num `char *`, `sizeof` dá o tamanho do ponteiro.
- Modificar um literal (`char *s = "abc"; s[0] = 'x';`) é UB: declare como `const char *`.
- `strcpy` e `strcat` não sabem o tamanho do destino: estouram o buffer. `strncpy` **não garante** o `'\0'` quando trunca. Prefira `snprintf(dst, sizeof dst, "%s", src)`, que sempre termina com `'\0'` e devolve quantos caracteres **teria** escrito (dá para detectar truncamento).
- Compare com `strcmp(a, b) == 0`, nunca `a == b` (isso compara endereços).
- `memcpy`, `memset` e `memcmp` trabalham com bytes e um tamanho explícito.

**6. `const` com ponteiros.** Leia da direita para a esquerda:

| Declaração | Pode mudar `p`? | Pode mudar `*p`? |
|---|---|---|
| `const int *p` (= `int const *p`) | sim | **não** |
| `int *const p` | **não** | sim |
| `const int *const p` | não | não |

Parâmetro que a função só lê: `const uint8_t *dados` — documenta e o compilador cobra. No A1, registradores aparecem como `volatile uint32_t *const` (T03).

**7. Ponteiros para função.** `void (*cb)(int)` é um ponteiro para uma função que recebe `int`. Usado em callbacks (`registra_callback(trata_botao)`) e tabelas de estados. `typedef void (*callback_t)(int);` deixa legível.

**8. Erros clássicos.**
- **Não inicializado**: `int *p; *p = 5;` escreve num endereço aleatório (UB).
- **Nulo**: não testar o retorno de uma função que pode devolver `NULL`.
- **Pendurado** (*dangling*): devolver o endereço de uma variável local (`return &v;`) — ela deixa de existir quando a função retorna; ou usar memória depois de `free` (T03).
- **Fora do array**: `for (i = 0; i <= n; i++)` (um a mais); índice negativo; string sem `'\0'`. Muitas vezes não dá segfault — use `-fsanitize=address` (T09).

## Pratique
Use `~/treino-c/t02/`, compile com `-std=c11 -Wall -Wextra -g` e confira tudo no GDB.
1. Declare `int x = 5; int *p = &x;` e imprima `x`, `&x`, `p`, `*p` e `&p`. No GDB, confira com `p`, `p *p` e `x/4xb p`.
2. Escreva `troca(int *a, int *b)` e teste. Depois escreva `void min_max(const int *v, size_t n, int *min, int *max)`.
3. Com `uint32_t v[4]`, imprima `(void *)&v[0]`, `(void *)&v[1]` e `(void *)(v + 3)`. Quantos bytes entre eles?
4. Imprima `sizeof v / sizeof v[0]` no `main` e dentro de uma função que recebe `int v[]`. Leia o aviso do gcc.
5. Percorra um array com ponteiro (`for (const int *p = v; p < v + n; p++)`) e some os elementos.
6. Preveja e confira: `int v[] = {5, 10, 15}; int *p = v; int a = *p++; int b = (*p)++;` — valores de `a`, `b`, `v[0]`, `v[1]`.
7. Escreva sua `size_t meu_strlen(const char *s)` com ponteiro e compare com `strlen`.
8. Com `char d[4]`, copie `"ABCDEF"` com `strncpy(d, "ABCDEF", sizeof d)` e examine `d` com `x/4cb d` no GDB. Há `'\0'`? Refaça com `snprintf` e veja o valor devolvido.
9. Escreva uma função que interpreta `"T=23;U=61"` e devolve os dois números por ponteiros (use `strtol` com o ponteiro de fim).
10. Declare `const int *a`, `int *const b` e tente as quatro atribuições (`a = …`, `*a = …`, `b = …`, `*b = …`). Quais o compilador recusa?
11. Escreva `int *cria(void) { int v = 42; return &v; }` e leia o aviso. O que acontece ao usar o ponteiro? (Compile também com `-fsanitize=address`.)
12. Crie uma tabela de ponteiros para função `{liga, desliga, pisca}` e chame a função de índice `i`.

## Armadilhas comuns
- `int *p, q;` declara **um** ponteiro (`p`) e um `int` (`q`). Prefira uma declaração por linha.
- Desreferenciar ponteiro não inicializado ou nulo; não testar o retorno de funções que podem falhar.
- Usar `sizeof` num parâmetro "array" esperando o tamanho do array (dá o tamanho do ponteiro).
- Esquecer o espaço do `'\0'`: `char s[3] = "LED";` compila (sem o terminador!) e quebra o `printf`.
- `strncpy` sem garantir o `'\0'`; `strcpy`/`sprintf` sem limite de tamanho.
- Comparar strings com `==`.
- Devolver endereço de variável local; guardar ponteiro para um buffer que vai ser reutilizado.
- Confundir `*p++` com `(*p)++`.
- Fazer aritmética em `void *` (é extensão do gcc, não C padrão): converta para `uint8_t *`.

## Gabarito
1. `*p` = 5; `p` e `&x` mostram o mesmo endereço; `&p` é outro endereço (o do próprio ponteiro).
2. `*min = *max = v[0]; for (size_t i = 1; i < n; i++) { if (v[i] < *min) *min = v[i]; if (v[i] > *max) *max = v[i]; }`.
3. 4 bytes de `v[0]` a `v[1]` e 12 de `v[0]` a `v + 3`.
4. 10 no `main`; 2 dentro da função no x86-64 (8 / 4), com `warning: 'sizeof' on array function parameter 'v' will return size of 'int *'`.
5. `soma += *p;` dentro do laço; `v + n` é o ponteiro "um depois do fim", que pode ser comparado mas não desreferenciado.
6. `a = 5`, `b = 10`, `v[0] = 5`, `v[1] = 11`.
7. `const char *p = s; while (*p) p++; return (size_t)(p - s);`.
8. `strncpy` copia `'A' 'B' 'C' 'D'` e **não** põe `'\0'` (o `printf("%s")` lê além do array: UB). `snprintf` grava `"ABC"` + `'\0'` e devolve 6 (o tamanho que a string inteira teria), sinal de truncamento.
9. `char *fim; long t = strtol(s + 2, &fim, 10);` e continue a partir de `fim`; confira se `fim` andou (houve número).
10. Recusa `*a = …` (o objeto apontado é `const` para `a`) e `b = …` (o ponteiro `b` é constante).
11. `warning: function returns address of local variable`. O uso é UB; o gcc chega a devolver `NULL` no lugar do endereço, e o programa dá segfault.
12. `void (*acoes[])(void) = {liga, desliga, pisca}; acoes[i]();` — confira `i` antes (índice fora da tabela pula para um endereço qualquer).
