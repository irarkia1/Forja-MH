## Resumo
**1. Ambiente.** No Ubuntu, o `python3` do sistema é usado pelo próprio sistema; desde o Ubuntu 23.04, `pip install` fora de um ambiente virtual é bloqueado com o erro *externally-managed-environment*. Crie um ambiente por projeto:
```bash
sudo apt install python3-venv
python3 -m venv .venv          # cria a pasta .venv (ponha no .gitignore)
source .venv/bin/activate      # o prompt mostra (.venv)
pip install pyserial matplotlib
pip freeze > requirements.txt  # registra as versões; outro PC: pip install -r requirements.txt
```

**2. Tipos e operações.** `int` (3), `float` (3.3), `str` ("3.3"), `bool` (True/False), `None`. `/` sempre dá float (`10 / 2` → `5.0`); `//` é divisão inteira (arredonda para baixo) e `%` o resto (`7 // 2` → 3, `7 % 2` → 1); `**` é potência. `"61" * 2` → `"6161"` (repete o texto!) — converta antes: `int("61")`, `float("3.29")`. Floats são aproximações binárias: `0.1 + 0.2` dá `0.30000000000000004`; compare com tolerância e use `round()` só para exibir.

**3. Controle e funções.**
```python
def resistor_led(v_fonte, v_f=2.0, i=0.010):   # v_f e i têm valor padrão
    """Resistor em série com um LED (M0.4.T01)."""
    return (v_fonte - v_f) / i

print(resistor_led(5))            # 300.0
print(resistor_led(3.3, i=0.005)) # argumento nomeado: 259.99999999999994 (≈ 260; float)
```
`for v in lista:` percorre; `range(5)` gera 0…4; `continue` pula para a próxima volta; `break` sai do laço; `if/elif/else`. Indentação **é** sintaxe (4 espaços).

**4. Strings, listas e dicionários.**
- Uma linha da serial: `linha = "T=23.5;U=61;V=3.29\r\n"`. `linha.strip()` tira espaços e `\r\n`; `.split(";")` quebra em lista; `"T=23.5".split("=")` → `["T", "23.5"]`.
- Listas: `m = [4.98, 5.01, 5.02]`; `m[0]`, `m[-1]` (último), `m[1:3]` (fatia: índices 1 e 2), `len(m)`, `m.append(x)`, `sorted(m)` (nova lista) × `m.sort()` (ordena **a própria** lista e devolve `None`).
- Compreensão: `[v for v in m if v > 5]`.
- Dicionário: `bom = {"R1": "10k", "C1": "100n"}`; `bom["R2"] = "1k"` acrescenta; `bom.get("D1", "?")` evita erro de chave; `for ref, valor in bom.items():`.
- **Atenção a referências**: `b = a` não copia a lista, dá outro nome para **a mesma** lista; uma função que recebe uma lista e faz `.sort()` ou `.append()` altera a lista de quem chamou. Copie com `a.copy()` ou `sorted(a)`.

**5. Arquivos e CSV.**
```python
import csv
with open("carga.csv", newline="") as f:          # with fecha o arquivo sozinho
    for linha in csv.DictReader(f):               # cada linha vira um dict pelo cabeçalho
        t, v = float(linha["tempo_s"]), float(linha["tensao_V"])

with open("saida.csv", "w", newline="") as f:
    w = csv.writer(f)
    w.writerow(["tempo_s", "tensao_V"])
    w.writerow([0.5, 1.97])
```
O `csv` devolve **strings**: converta com `float()`. O cabeçalho não entra nos dados do `DictReader`.

**6. Porta serial com pyserial.**
```python
import serial
with serial.Serial("/dev/ttyUSB0", 115200, timeout=1) as ser:
    for _ in range(10):
        bruto = ser.readline()            # bytes, ex.: b'3.29\r\n'; b'' se der timeout
        if not bruto:
            continue
        texto = bruto.decode("ascii", errors="replace").strip()
        print(float(texto))
```
`readline()` devolve **bytes** e espera até o `\n` ou até o `timeout`; sem `timeout`, pode travar para sempre. Para testar sem placa, use `serial.serial_for_url("loop://", timeout=1)`: tudo o que você escreve volta na leitura. Só um programa abre a porta por vez (feche o screen e o monitor serial da IDE).

**7. Estatística e gráfico.**
```python
import statistics as st
v = [4.98, 5.02, 5.00, 4.96, 5.04]
st.mean(v)     # 5.0
st.stdev(v)    # desvio-padrão AMOSTRAL (divide por n−1) ≈ 0.0316
st.pstdev(v)   # desvio-padrão POPULACIONAL (divide por n) ≈ 0.0283
```
Para repetições de uma medição (amostra), use `stdev`. Gráfico:
```python
import matplotlib.pyplot as plt
plt.plot(t, v, "o-")                 # x primeiro, depois y
plt.xlabel("tempo (s)"); plt.ylabel("tensão (V)"); plt.grid(True)
plt.title("Carga do capacitor (R = 10 kΩ, C = 100 µF)")
plt.savefig("carga.png", dpi=150)    # grave ANTES de plt.show()
plt.show()
```
Num computador sem tela (por ssh), use só `savefig`.

## Armadilhas comuns
- `pip install` fora do venv (erro *externally-managed-environment*) ou com `sudo`.
- Somar ou multiplicar strings lidas do CSV/serial sem converter (`"61" * 2` = `"6161"`).
- Comparar `readline()` (bytes) com str: `b"OK\r\n" == "OK"` é falso; decodifique e use `strip()`.
- `serial.Serial` sem `timeout`: o programa trava se a placa parar de enviar.
- `lista.sort()` dentro de uma função alterando a lista original; `x = lista.sort()` deixa `x = None`.
- Usar `pstdev` para repetições de medição (subestima a dispersão), ou não dizer qual desvio usou.
- Esquecer o `newline=""` ao abrir CSV (linhas em branco extras em alguns sistemas).
- Comparar floats com `==`.
