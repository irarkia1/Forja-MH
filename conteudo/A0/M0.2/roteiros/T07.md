## Resumo
**1. O que é uma EDO.** Uma equação que envolve uma função desconhecida y(t) e suas derivadas. Classificação:
- **Ordem:** a maior derivada que aparece. y' + 2y = 0 é de 1ª ordem; y'' + 3y' + 2y = 0, de 2ª.
- **Linear:** y e suas derivadas aparecem só elevadas a 1 e não multiplicadas entre si (y·y' ou sen y tornam a EDO não linear). Circuitos com R, L e C ideais dão EDOs lineares; um diodo deixa a EDO não linear.
- **Homogênea:** o lado direito (o termo que não tem y) é zero. y'' + 4y = 0 é homogênea; y'' + 4y = sen t não é (o termo de fora é a "fonte").
- **Verificar uma solução:** substitua e veja se a igualdade vale para todo t. Ex.: y = e^(−2t) em y' + 2y = 0: −2e^(−2t) + 2e^(−2t) = 0 ✔.

**2. EDO linear de 1ª ordem — o circuito RC.** Fonte V, resistor R, capacitor C, v = tensão no capacitor. Kirchhoff: V = R·i + v, com i = C·dv/dt (T05):

> R·C·dv/dt + v = V   ⇔   dv/dt = (V − v)/τ,  τ = R·C

**Solução por separação de variáveis.** dv/(V − v) = dt/τ. Integrando os dois lados (T06): −ln|V − v| = t/τ + K ⇒ V − v = A·e^(−t/τ) ⇒ v(t) = V − A·e^(−t/τ). A condição inicial v(0) = v₀ dá A = V − v₀:

> **v(t) = v∞ + (v₀ − v∞)·e^(−t/τ)**   (v∞ = valor final)

É a "fórmula única" do M0.4.T07, agora deduzida. Toda EDO da forma dy/dt + y/τ = K tem essa solução, com y∞ = K·τ. **Para reconhecer τ**, ponha a EDO na forma "dy/dt + (1/τ)·y = …": em dv/dt + 50·v = 250, 1/τ = 50 ⇒ τ = 20 ms e v∞ = 250/50 = 5.

**Exemplo 1.** Capacitor com v₀ = 2 V, ligado por R a uma fonte de 10 V, τ = 1 ms. v(2 ms) = 10 + (2 − 10)·e^(−2) = 10 − 8 × 0,1353 = **8,92 V**.

**RL.** Kirchhoff: V = R·i + L·di/dt ⇒ di/dt + (R/L)·i = V/L ⇒ τ = **L/R**, i∞ = V/R, mesma solução. **Exemplo 2:** 12 V, R = 6 Ω, L = 30 mH, i(0) = 0: τ = 5 ms, i(t) = 2·(1 − e^(−t/5 ms)) A. Tempo para chegar a 1,5 A: e^(−t/τ) = 0,25 ⇒ t = τ·ln 4 = **6,93 ms**.

**Com mais resistores:** troque o resto do circuito pelo equivalente de Thévenin visto pelo C ou pelo L (M0.4.T05): τ = R_th·C ou L/R_th, e o valor final vem de V_th.

**3. EDO linear homogênea de 2ª ordem.** a·y'' + b·y' + c·y = 0. Chute y = e^(st) (porque a derivada de uma exponencial é ela mesma vezes s): a·s²·e^(st) + b·s·e^(st) + c·e^(st) = 0 ⇒ a **equação característica**

> a·s² + b·s + c = 0

O discriminante Δ = b² − 4ac (T01) decide tudo:

| Raízes | Solução geral | Nome (em circuitos) | Comportamento |
|---|---|---|---|
| Reais distintas s₁, s₂ (Δ > 0) | A·e^(s₁t) + B·e^(s₂t) | superamortecida | volta devagar, sem oscilar |
| Real dupla s (Δ = 0) | (A + B·t)·e^(st) | criticamente amortecida | o retorno mais rápido sem oscilar |
| Complexas −α ± j·ωd (Δ < 0) | e^(−αt)·(A·cos ωd·t + B·sen ωd·t) | subamortecida | oscila com amplitude decrescente |

As raízes complexas vêm do T04: e^((−α + jωd)t) = e^(−αt)·(cos ωd·t + j·sen ωd·t) pela fórmula de Euler; combinando as duas raízes conjugadas sobra uma solução real.

**As constantes A e B saem das duas condições iniciais** (um sistema 2×2, T08). **Exemplo 3 (superamortecida).** y'' + 3y' + 2y = 0, y(0) = 1, y'(0) = 0. s² + 3s + 2 = (s + 1)(s + 2) = 0 ⇒ s = −1, −2. y = A·e^(−t) + B·e^(−2t). Condições: A + B = 1 e −A − 2B = 0 ⇒ A = 2, B = −1 ⇒ **y = 2e^(−t) − e^(−2t)**.
**Exemplo 4 (subamortecida).** y'' + 2y' + 5y = 0, y(0) = 1, y'(0) = 0. s = (−2 ± √(4 − 20))/2 = −1 ± j2 ⇒ α = 1, ωd = 2. y = e^(−t)·(A·cos 2t + B·sen 2t). y(0) = A = 1; y'(0) = −A + 2B = 0 ⇒ B = 0,5 ⇒ **y = e^(−t)·(cos 2t + 0,5·sen 2t)**.
**Exemplo 5 (crítica).** y'' + 4y' + 4y = 0: s = −2 (dupla) ⇒ y = (A + Bt)·e^(−2t). Com y(0) = 1, y'(0) = 0: A = 1, B − 2A = 0 ⇒ B = 2.

**4. O circuito RLC série.** Fonte V, R, L e C em série; corrente i, tensão v no capacitor. Kirchhoff: V = R·i + L·di/dt + v, com i = C·dv/dt:

> L·C·v'' + R·C·v' + v = V   ⇔   v'' + (R/L)·v' + v/(LC) = V/(LC)

Equação característica s² + (R/L)·s + 1/(LC) = 0, que se escreve s² + 2α·s + ω₀² = 0 com:

> **α = R/(2L)** (amortecimento, 1/s)    **ω₀ = 1/√(LC)** (frequência natural, rad/s)    **ωd = √(ω₀² − α²)** (frequência amortecida)

- α > ω₀: superamortecido; α = ω₀: crítico, que acontece em **R = 2·√(L/C)**; α < ω₀: subamortecido, oscila em ωd.
- O fator de amortecimento ζ = α/ω₀ resume: ζ < 1 oscila, ζ = 1 crítico, ζ > 1 não oscila.
- A resposta completa a um degrau é v(t) = V (valor final) + solução homogênea; as constantes vêm de v(0) e i(0) = C·v'(0).

**Exemplo 6.** L = 10 mH, C = 1 µF, R = 50 Ω. ω₀ = 1/√(10⁻²·10⁻⁶) = 1/10⁻⁴ = **10 000 rad/s** (f₀ ≈ 1,59 kHz). α = 50/(2 × 0,01) = **2500 s⁻¹**. Como α < ω₀, é subamortecido: ωd = √(10⁸ − 6,25 × 10⁶) ≈ **9682 rad/s** (≈ 1,54 kHz), ζ = 0,25. A oscilação decai com e^(−2500t): constante de tempo do envelope 1/α = 0,4 ms. R crítico = 2·√(0,01/10⁻⁶) = **200 Ω**.

Onde isso aparece: o "ringing" de uma borda digital numa trilha longa (a indutância da trilha com a capacitância da entrada), o filtro LC de um conversor buck, a resposta de um sensor com massa e mola (acelerômetro MEMS), e o próprio oscilador LC.

**5. Resolvendo numericamente.** Quando não há solução fechada (diodo, saturação), integre passo a passo. Método de Euler para v' = (V − v)/τ:

```python
V, tau, h = 10.0, 1e-3, 1e-6
v, t = 2.0, 0.0
while t < 2e-3:
    v += h * (V - v) / tau   # v(t+h) ≈ v(t) + h·v'(t)
    t += h
print(v)   # ≈ 8.917, compare com o Exemplo 1
```
Para trabalho sério, use `scipy.integrate.solve_ivp` ou um simulador SPICE (ngspice, LTspice).

## Armadilhas comuns
- Ler τ errado: em dv/dt + 50v = 250, τ = 1/50 s, não 50 s; e o valor final é 250/50 = 5, não 250.
- Aplicar a condição inicial antes de escrever a solução geral completa.
- Na raiz dupla, esquecer o termo B·t·e^(st) (só e^(st) não basta para duas condições iniciais).
- Confundir ω₀ com ωd, ou rad/s com Hz.
- Usar α = R/L (é R/(2L)) no RLC série.
- Achar que "criticamente amortecido" oscila um pouco (não oscila; é a fronteira).
