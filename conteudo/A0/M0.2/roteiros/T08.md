## Resumo
**1. Vetores.** Um vetor é uma lista ordenada de números, u = (u₁, u₂, …, uₙ); geometricamente, uma seta com tamanho e direção.
- **Soma:** componente a componente, (1, 2) + (3, −1) = (4, 1) (regra do paralelogramo: é como somar fasores no T04).
- **Produto por escalar:** 3·(1, 2) = (3, 6) (estica a seta; com escalar negativo, inverte).
- **Norma (tamanho):** |u| = √(u₁² + u₂² + … + uₙ²). |(2, −1, 2)| = √(4 + 1 + 4) = 3.
- **Produto escalar:** u·v = u₁v₁ + u₂v₂ + … + uₙvₙ = |u|·|v|·cos θ. Ele mede "o quanto um vetor aponta na direção do outro". u·v = 0 ⇔ **ortogonais** (perpendiculares).

**Exemplo 1 (ângulo entre vetores).** u = (2, 1), v = (1, 3): u·v = 2 + 3 = 5; |u| = √5; |v| = √10; cos θ = 5/√50 = 0,707 ⇒ **θ = 45°**.

Aplicação em sinais: se você guarda N amostras de dois sinais como vetores, o produto escalar dividido por N é a média do produto — para tensão e corrente amostradas, é a **potência média** P = (1/N)·Σ v[k]·i[k]. Senoide e cossenoide de mesma frequência, amostradas num período inteiro, são ortogonais (produto escalar zero): é a base da transformada de Fourier.

**2. Matrizes.** Uma matriz m×n tem m linhas e n colunas. Soma: elemento a elemento (mesmas dimensões).
- **Produto** A·B (A é m×n, B é n×p, resultado m×p): o elemento (i, j) é o produto escalar da **linha i de A** com a **coluna j de B**.

> [[1, 2], [3, 4]] · [[5, 6], [7, 8]] = [[1·5 + 2·7, 1·6 + 2·8], [3·5 + 4·7, 3·6 + 4·8]] = [[19, 22], [43, 50]]

- **Em geral A·B ≠ B·A** (o produto não é comutativo). Faça B·A no exemplo e confira: [[23, 34], [31, 46]].
- **Identidade** I: 1 na diagonal, 0 fora; A·I = I·A = A.
- **Transposta** Aᵀ: troca linhas por colunas. (A·B)ᵀ = Bᵀ·Aᵀ.

**3. Determinante.**
- 2×2: det [[a, b], [c, d]] = **a·d − b·c**. Ex.: det [[3, −2], [4, 5]] = 15 − (−8) = 23.
- 3×3 (expansão pela 1ª linha, sinais + − +):

> det [[a, b, c], [d, e, f], [g, h, i]] = a(ei − fh) − b(di − fg) + c(dh − eg)

  Ex.: det [[2, 1, 0], [1, 3, 1], [0, 1, 2]] = 2(6 − 1) − 1(2 − 0) + 0 = **8**.
- Significado geométrico: o fator pelo qual a matriz muda áreas (ou volumes). **det = 0** ⇒ a matriz "achata" o espaço ⇒ ela **não tem inversa**.

**4. Inversa.** A⁻¹ é a matriz tal que A·A⁻¹ = I. Para 2×2:

> [[a, b], [c, d]]⁻¹ = (1/(ad − bc)) · [[d, −b], [−c, a]]

(troque a diagonal principal, mude o sinal da outra, divida pelo determinante). Ex.: [[2, 1], [5, 3]]⁻¹ = (1/1)·[[3, −1], [−5, 2]].

**5. Sistemas lineares A·x = b.**
- **Eliminação de Gauss:** escreva a matriz aumentada [A | b] e use operações de linha (trocar linhas, multiplicar uma linha por número ≠ 0, somar a uma linha um múltiplo de outra) até a forma escalonada; depois resolva de baixo para cima.

**Exemplo 2.** x + y + z = 6; 2x − y + z = 3; x + 2y − z = 2.
1. L2 ← L2 − 2·L1: −3y − z = −9. L3 ← L3 − L1: y − 2z = −4.
2. L3 ← 3·L3 + L2: 3y − 6z − 3y − z = −12 − 9 ⇒ −7z = −21 ⇒ **z = 3**.
3. Volta: y − 2·3 = −4 ⇒ **y = 2**; x + 2 + 3 = 6 ⇒ **x = 1**.

- **Regra de Cramer:** se det(A) ≠ 0, xₖ = det(Aₖ)/det(A), em que Aₖ é A com a coluna k trocada por b. Ótima para 2×2 e 3×3 à mão; inviável para sistemas grandes. **Exemplo 3:** 2,5·x − y = 10 e −x + 1,5·y = 0: det = 3,75 − 1 = 2,75; x = det [[10, −1], [0, 1,5]]/2,75 = 15/2,75 = **5,455**; y = det [[2,5, 10], [−1, 0]]/2,75 = 10/2,75 = **3,636**.
- **Classificação:** det(A) ≠ 0 ⇒ **solução única**. det(A) = 0 ⇒ **nenhuma** solução (equações contraditórias, retas paralelas) ou **infinitas** (equações repetidas, retas coincidentes). Ex.: 2x + 4y = 6 e x + 2y = 3 são a mesma reta (infinitas); 2x + 4y = 6 e x + 2y = 5 são paralelas (nenhuma). Num circuito, det = 0 costuma indicar um nó "flutuando" (sem caminho para o terra) ou uma equação esquecida.

**6. Análise nodal na forma matricial.** Com N nós (fora o terra), a lei de Kirchhoff das correntes em cada nó dá G·v = i:
- **G (condutâncias, em S):** na diagonal, Gₖₖ = **soma das condutâncias ligadas ao nó k**; fora da diagonal, Gₖₘ = **−(condutância entre os nós k e m)**. G é simétrica.
- **v:** tensões dos nós em relação ao terra (as incógnitas).
- **i:** correntes de fontes **injetadas** em cada nó. Uma fonte de tensão E em série com R vira (Norton) uma fonte de corrente E/R injetada no nó, com R ligada ao terra.

**Exemplo 4.** Fonte de 10 V em série com R1 = 1 kΩ ligada ao nó 1; R2 = 2 kΩ do nó 1 ao terra; R3 = 1 kΩ entre os nós 1 e 2; R4 = 2 kΩ do nó 2 ao terra. Trabalhando em mS, mA e V:

> G = [[1 + 0,5 + 1, −1], [−1, 1 + 0,5]] = [[2,5, −1], [−1, 1,5]]    i = [10 V/1 kΩ, 0] = [10, 0] mA

Essa é exatamente a equação do Exemplo 3: **v1 = 5,455 V, v2 = 3,636 V**. Conferência: a corrente em R4 é 3,636/2 = 1,818 mA, igual à de R3: (5,455 − 3,636)/1 = 1,819 mA ✔.

```python
import numpy as np
G = np.array([[2.5, -1.0],
              [-1.0, 1.5]])   # mS
i = np.array([10.0, 0.0])     # mA
v = np.linalg.solve(G, i)     # V  -> [5.4545 3.6364]
print(v, np.linalg.det(G))
```
Use `np.linalg.solve` (e não `np.linalg.inv(G) @ i`): é mais rápido e numericamente mais estável.

## Armadilhas comuns
- Multiplicar matrizes elemento a elemento (isso é o `*` do NumPy; o produto de matrizes é `@`).
- Achar que A·B = B·A.
- Errar o sinal no determinante 3×3 (o termo do meio é **menos**) ou na inversa 2×2 (troca a diagonal, muda o sinal da outra).
- Dividir por zero na regra de Cramer: se det = 0, não há solução única.
- Na matriz G, pôr a condutância entre nós com sinal **positivo** fora da diagonal, ou esquecer de somar na diagonal o resistor que vai ao terra.
- Misturar unidades (Ω com S, mA com A): escolha kΩ↔mS, mA e V e mantenha.
