# Experiência do usuário

## Princípios
1. **Dois cliques até estudar.** Abrir o site → "Continuar" leva direto ao
   inimigo atual com o cronômetro pronto.
2. **O jogo é a moldura, o estudo é o quadro.** Nas telas de estudo e de prova,
   a arte some para o canto; texto legível, fundo calmo, nada piscando.
3. **Sempre mostrar o próximo passo.** Toda tela tem um botão principal claro.
4. **Feedback honesto.** O painel mostra a previsão real, não a desejada.
5. **Teclado em tudo.** Setas, Enter, Esc, números para responder.

## Jornada de um dia típico
1. Abre `meh-eng.com/estudos` → acampamento.
2. Aviso: "3 fantasmas hoje (≈ 8 min)". Enfrenta os três.
3. "Continuar" → mapa centraliza no inimigo atual → Enter.
4. Roteiro + cronômetro. Estuda 2 blocos de 50 min, com check-ins.
5. Vida do inimigo zera → nota pessoal → ataca → vitória.
6. Volta ao acampamento: +XP, skill nova disponível, painel da semana.

## Celular
- Acampamento, fantasmas, painel e **check-in do estudo offline** funcionam no
  celular (≥ 360 px).
- O mapa vira lista vertical abaixo de 600 px de largura.
- Provas de chefe longas: recomendadas no computador (aviso, não bloqueio).

## Acessibilidade
- Contraste AA em todas as telas de texto; quiz não depende de cor.
- Fonte pixel **só em títulos**; enunciados em fonte legível, 18 px.
- Animações respeitam `prefers-reduced-motion`.
- Tudo navegável por teclado, com foco visível.
