# Laboratórios e bancada

Equipamento comprado **quando o ato precisa**, não antes. Valores são ordem de
grandeza em reais (2026) e precisam ser cotados (PENDENCIAS P8). Sempre que
possível, usar o laboratório da empresa.

## A0–A1 — Bancada básica (~R$ 2.500)
| Item | Para quê |
|---|---|
| Multímetro true-RMS | Tudo |
| Fonte de bancada 0–30 V / 0–5 A | Circuitos, protótipos |
| Ferro de solda com controle de temperatura + acessórios | Solda THT |
| Protoboards, jumpers, kit de componentes | M0.4 em diante |
| Arduino Uno/Nano, STM32 Nucleo, ESP32 DevKit (2 de cada) | A1 |
| Analisador lógico 8 canais (clone Saleae) | M1.1, M1.5 |
| Osciloscópio 2 canais 100 MHz | M0.5 em diante |
| Tapete e pulseira ESD | Segurança e componentes |

## A2 — Protótipo de PCB (~R$ 3.500)
| Item | Para quê |
|---|---|
| Estação de ar quente | Retrabalho SMD |
| Microscópio estéreo ou digital | Inspeção |
| Chapa quente (hot plate) | Refusão de placas pequenas |
| Fresadora CNC pequena (opcional) | PCB caseira |
| Pedidos a fabricante (5–10 placas por rodada) | M2.5, M2.10, M2.11 |
| Medidor de corrente de baixa potência (PPK2 ou similar) | M1.11 |

## A6 — Silício (~R$ 2.000 + shuttle)
| Item | Para quê |
|---|---|

## A7 — Laboratório de materiais (~R$ 4.000)
| Item | Para quê |
|---|---|
| Forno/mufla pequena, hot plate com agitador | Cerâmicas, óxidos |
| Vidraria, reagentes, EPI, capela ou ventilação | Química segura |
| Spin coater caseiro, UV para fotolitografia | M7.4 |
| Câmara de vácuo simples (opcional, avançado) | Deposição de filmes |
| Padrões de referência (termômetro calibrado, massas) | M7.5 |

> **Segurança primeiro**: A7 envolve químicos e calor. O tópico M7.2.T07
> (segurança química) é pré-requisito de todos os ⚒ do M7.3 e M7.4.
