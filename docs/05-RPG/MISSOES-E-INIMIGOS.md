# Missões e inimigos

## Missão = fase = módulo
Cada fase tem: nome, região, trilha (cor), lista de inimigos, chefe, e uma
**missão narrativa** de uma linha (ex.: M0.4 — "Religue o gerador da vila sem
queimar a última lâmpada").

## Inimigos
| Classe | Tema | Visual | Regra |
|---|---|---|---|
| **Comum** | Tópico teórico | Monstro da região | Tempo mínimo + combate (poder da fase) |
| **Elite** ⚒ | Tópico prático | Mesmo monstro com armadura | + evidência de laboratório; poder +25% |
| **Fantasma** | Revisão espaçada | Translúcido | 2–3 questões, sem dano e sem skills |
| **Chefe** | Prova do módulo | Grande, arte própria por variante | Variante sorteada |

O **nome** do inimigo é o título do tópico ("Leis de Kirchhoff",
"Árvore de Clock", "Fotolitografia EUV"). O sprite vem do **tipo do tema**:

| Tipo de tema | Família de monstro |
|---|---|
| Matemática / física | Golens de runas |
| Componente passivo | Criaturas de resistor, capacitor, indutor |
| Firmware / protocolo | Serpentes de bits, aranhas de barramento |
| PCB / layout | Trepadeiras de trilha |
| RF / EMC | Espíritos de onda |
| Fabricação | Autômatos de linha de produção |
| Silício | Cristais vivos |
| Sensores | Quimeras de laboratório |

## Evidência de laboratório
| Tipo | Exemplo |
|---|---|
| Foto | Montagem na protoboard com o multímetro mostrando o valor |
| Vídeo curto | LED respondendo ao sensor |
| Link | Repositório com o firmware e o README |
| Arquivo | Planilha de medição, captura do analisador lógico |

A evidência precisa de uma descrição: o que foi feito, o que foi medido, o que
deu diferente do esperado. Ela também alimenta o **diário de laboratório**,
que vira portfólio.
