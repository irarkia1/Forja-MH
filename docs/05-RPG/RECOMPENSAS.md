# Recompensas

## No jogo
| Recompensa | Como ganha |
|---|---|
| **XP e nível** | Estudo, vitórias, fantasmas, laboratório (BALANCEAMENTO.md) |
| **Pontos de skill** | 2 por nível do personagem (só isso) |
| **Títulos** | Por horas acumuladas (PERSONAGEM-E-SKILLS.md) |
| **Relíquias** | Uma por projeto integrador, exibida no acampamento: *Rádio do Explorador* (A1), *Placa Primordial* (A2), *Coração de Silício-Mãe — o seu ESP32* (A3), *Selo do Produto* (A4), *Engrenagem da Fábrica* (A5), *Cristal do Chip* (A6), *Olho do Sensor* (A7) |
| **Visual do boneco** | Roupa nova a cada ato concluído |
| **Conquistas** | Lista abaixo |

| Conquista | Condição |
|---|---|

| Purista | Vencer O Purista |
| Sem Arranhões | Vencer um chefe sem levar dano |
| Sortudo | Sobreviver a um chefe com menos de 5% de vida |
| Muralha | Chegar a 80% de Defesa |

| Calibrado | Oráculo Cego com ≥ 90% |
| Colecionador | Enfrentar as 20 variantes de chefe |
| Contestador | Ter uma contestação de questão aceita |

## Fora do jogo (recompensas reais)
O Matheus define uma recompensa real por marco — de preferência **ferramenta
para a bancada do próximo ato** (LABORATORIOS-E-BANCADA.md), para que o prêmio
puxe o próximo passo.

| Marco | Sugestão |
|---|---|
| Fim do A0 | Osciloscópio |
| Fim do A1 | Estação de ar quente + microscópio |
| Fim do A2 | Forno de refusão |
| Fim do A3 | VNA + analisador de espectro portátil |
| Cada 1.000 h | Um livro técnico da lista de fontes |
