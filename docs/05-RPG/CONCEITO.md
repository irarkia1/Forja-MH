# Conceito

## A história em um parágrafo
O mundo foi construído por máquinas que ninguém mais entende. Você é um
aprendiz na **Forja M&H**, em ruínas, e decide refazer, sozinho, todo o caminho:
do primeiro circuito ao chip, do chip ao sensor. Cada tema que você ainda não
domina é um monstro no caminho. Cada módulo termina com um guardião.

## O loop

```
        ┌──────────── ACAMPAMENTO ◀───────────────┐
        │  skills · painel · fantasmas · diário    │
        ▼                                          │
     MAPA (linha) ── escolhe caminho ──▶ FASE      │
                                          │        │
                     ┌────────────────────┘        │
                     ▼                             │
                 INIMIGO: estudar ⏱ → atacar (3 questões; erro = dado de dano)
                     │                 │           │
                  vitória           derrota ───────┘ (expulso)
                     │
               próximo inimigo ... → CHEFE (variante sorteada)
                                        │
                                     vitória → próxima fase liberada
```

## Pilares
1. **O estudo é a jogabilidade.** O que avança o jogo é tempo de estudo válido
   e resposta certa. Não existe atalho por grind.
2. **Simples de jogar.** Uma linha, setas ou clique, Enter para entrar.
   Nada de reflexo ou destreza.
3. **Consequência.** Perder dói (expulsão, cooldown), mas não apaga estudo real.
4. **Variedade nos chefes.** 20 variantes sorteadas; nunca as mesmas 3 seguidas.
5. **Ajuda que ensina.** Skills facilitam a prova pelo caminho do aprendizado,
   e o custo delas é pago com revisão e laboratório.
